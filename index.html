Embedded relational database technology

Innervex DataCore

Enterprise-grade Java database technology derived from Apache Derby, prepared for focused maintenance, usability improvements, and platform modernization.

Developed by Innervex Technologies Private Limited.

Built to become an Innervex-owned and Innervex-maintained database foundation, with performance improvements guided by measurement and compatibility.

Read project overview View architecture Benchmark report Open public API Getting started

Innervex DataCore is an independent open-source project based on Apache Derby. It is not an official Apache Derby release and is not affiliated with, endorsed by, or maintained by the Apache Software Foundation.

Innervex and Innervex DataCore branding belong to Innervex Technologies Private Limited.

Embedded Engine

A compact relational database engine for Java applications, with SQL, JDBC, transactions, locking, recovery, and local storage.

Network Access

Includes Derby network server and client components for applications that need remote JDBC access.

Developer Build

The primary build remains Ant-based. Development jars are generated under jars/sane/.

Build Locally

From the repository root, run the Ant build. NetBeans uses the same project build script.

ant -quiet clobber buildsource buildjars

Performance Baseline

DataCore performance work is tracked through repeatable embedded benchmark workloads. The current local benchmark report can be opened from this distribution after running the report target.

Latest Report
